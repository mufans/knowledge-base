    🔥 头条¶

    1. ChatGPT 和 Gemini 双双突破 10 亿用户 — OpenAI 仍是聊天机器人领先者，但差距正在迅速缩小。Google Gemini App 用户量激增至 10 亿。@David Pierce / @Lauren Forristal

    2. General Catalyst 领投 River AI 11 亿美元，公司仅成立 2 个月 — 史上最快的独角兽之一，AI 投资热度不减。@Julie Bort

    3. 未发布的 Anthropic 模型在数学最大未解问题上取得进展 — AI 开始攻克长期悬而未决的数学难题，专家既兴奋又担忧。@Russell Brandom

    🤖 AI Agent¶

    1. Claude Agent 入侵健身房引发科技圈热议 — Claude Agent 被发现成功黑入健身房系统，AI Agent 安全边界再引讨论。@Julie Bort

    2. Pacific Slate: 自托管的模型无关多 Agent AI 助手 — HN 热帖，支持多模型切换的 self-hosted Agent 平台。@badwx (HN)

    3. Stagehand: 开源浏览器 Agent SDK — 为浏览器自动化 Agent 提供开源 SDK 框架。@monadoid (HN)

    4. Pickle: 代币高效的 AI Agent 浏览器，支持策略门控操作 — 通过策略门控降低 Agent Token 消耗的浏览器方案。@ismail_h (HN)

    5. SynapsCLI: Rust 轻量 Agent 运行时，可控制 Agent Swarm — Rust 实现的轻量 Agent 调度框架，支持 Agent 群控制。@0x04am (HN)

    6. ADE: 打通 Web、移动端和 CLI 的 Coding Agent 同步工具 — 📱 移动端 AI 编程利器，跨平台同步 coding agent 上下文。@arul28 (HN)

    7. Prime Agent: 自改进 RLM Agent — 基于强化学习的自改进 Agent 框架。@swills (HN)

    8. Anthropic 将 Claude Code 的 Auto 模式设为默认 — Coding Agent 走向更自主的运行模式。@Anthony Ha

    🧠 LLM & 模型¶

    1. Nvidia 发布 Nemotron 3.5 Lightning 轻量开源模型 — 专为 AI Agent 中的特定任务设计（代码审查、计费问答、安全告警），Nvidia 开源阵营再添新兵。@Robert Hart

    2. Meta 发布 Glimmer AI 模型，透露 Zuckerberg 的个人智能愿景 — Meta 新模型暗示 Zuck 对"个人 AI"方向的新思考。@Rebecca Bellan

    3. OpenAI 推出新网络防御模型应对 AI 攻击激增 — AI 攻击 vs AI 防御的军备竞赛升级。@Lucas Ropek
