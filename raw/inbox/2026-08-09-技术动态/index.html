    技术动态 - 2026-08-09¶

    来源：InfoQ、Solidot、Dev.to、OSChina | 采集时间：10:00 AM

    AI & 大模型¶

    1. MCP 迎来最大更新：重回上古时代HTTP
      MCP 协议发布以来最大更新，出人意料地回归 HTTP 架构，大幅简化实现和部署复杂度。

    2. Claude Code之父：每半年清空一次claude.md、skills和hooks，模型自己会想办法
      Claude Code 创建者分享 Agent 开发反直觉实践——定期清空配置促使 AI 更灵活地自适应任务。

    3. 蚂蚁开源Avernet，为多智能体协作搭建"操作系统"
      蚂蚁集团开源多智能体协作基础设施 Avernet，内部12大业务跑通，任务完成率超90%。

    4. DeepSeek要涨价，Meta新模型打出更低"骨折价"
      Meta 推出编程智能体 Muse Code 及编程优化模型 Muse Spark 1.2，正面迎战 DeepSeek 涨价。

    5. Jeff Dean离职前最后一次对话：我低估了AI，也看清了创业者的唯一生路
      Google 传奇 Jeff Dean 离职前反思：模型只是拼图一块，真正该做的是构建解决真实问题的完整系统。

    6. 角色边界重塑，全栈取代分工：快手AI生产力体系成形
      快手用 AI 彻底重塑研发流程，全栈模式取代传统角色分工，需求交付链路全面提速。

    7. 字节跳动开发 10 万亿参数模型
      字节正在训练 10 万亿参数大模型，规模接近 Anthropic Mythos 5，目前处于预训练阶段。

    AI 工程化 & 基础设施¶

    1. 微软公布 AI 智能体 LLM 路由方案，最高节省 85% 成本
      微软面向 AKS 推出三层 LLM 路由架构，智能调度不同规格模型，大幅降低 AI Agent 推理成本。

    2. AMD 收购将权重直接刻在芯片上的 AI 初创公司 Taalas
      收购模型专用集成电路公司 Taalas，其 6nm 推理芯片比英伟达 GPU 快 48 倍，但换模型需重新设计芯片。

    开源 & 开发者工具¶

    1. 甲骨文对 OpenJDK 项目禁止 AI 生成代码
      Oracle 以安全、隐私和知识产权风险为由，禁止将 AI 生成代码提交到 OpenJDK 代码库。

    2. Cherry Studio V2.0：从聊天客户端到全能 AI 工作站
      开源 AI 客户端 Cherry Studio 发布 V2 重大升级，从聊天工具进化为 Agent 自主执行的一站式 AI 工作站。

    3. 为 Claude Code 构建持久化记忆系统
      开发者分享为 Claude Code 构建持久记忆的方案，解决 AI 编码助手遗忘代码库上下文的问题。

    移动端 & 端侧¶

    1. HarmonyOS 7 Beta 2 + DevEco CLI：AI 赋能鸿蒙应用开发
      HarmonyOS 7 Beta 2 新增 AI 故障分析能力，DevEco CLI 作为 AI Agent 原子化能力调度枢纽，让 AI 更懂鸿蒙开发。
