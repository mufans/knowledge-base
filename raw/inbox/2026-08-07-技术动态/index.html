    技术动态 - 2026年8月7日¶

    来源：InfoQ、开源中国、dev.to、Solidot

    AI & 大模型¶

    1. 哈萨比斯卸任谷歌 DeepMind CEO，Jeff Dean 等四位谷歌大脑元老集体离职创业
      谷歌 AI 权力中心罕见系统性重排：诺奖得主 Hassabis 改任首席科学家，Jeff Dean 与 Ghemawat、Vinyals、Quoc Le 共同创立公益性 AI 企业 Discovery Loop。

    2. Jeff Dean 离职前最后一次对话：模型只是系统的一块拼图
      "你要做的，是构建一个能解决真正有趣问题的完整系统。"Jeff Dean 强调 AI 创业者的生路不在模型卷，而在系统级创新。

    3. DeepSeek 警告：API 整体定价近期将大幅上调
      DeepSeek 开放平台官方通知，计划近期整体上调 API 服务定价，预计涨幅较大。InfoQ 快讯 + OSChina 报道。

    4. 字节跳动创始人张一鸣三次否决：禁止蒸馏任何外部模型
      张一鸣在 Seed 团队全员会上明令禁止蒸馏闭源或开放权重的任何外部模型，The Information 独家报道。

    5. 字节发布 SeedRealtime 音视频全双工大模型
      采用统一架构原生融合音频、视频与文本，实现"边看、边听、边说"的实时多模态交互体验。

    6. Meta 发布终端编程 Agent「Muse Code」和 Muse Spark 1.2 模型
      一行 curl 命令即可安装的终端编程 agent，驱动模型 Muse Spark 1.2 同步发布，直接对标 Claude Code 生态。

    7. 小米正式开源自研具身基座模型 Xiaomi-Robotics-1
      1000 个机器人训练场景、1700 种物体、10 万小时训练数据，在 4 个主流 benchmark 上展现竞争力。

    编程 & 开源¶

    1. TypeScript 7 用 Go 原生重写：性能大幅提升
      TypeScript 编译器从 TypeScript/JavaScript 迁移到 Go 实现，编译速度提升 10-25 倍，生态工具链面临重塑。

    2. MCP 迎来最大更新：回归 HTTP 协议
      MCP 协议发布以来最大更新，官方选择回归上古 HTTP 时代，放弃此前推动的 Streamable HTTP 复杂路线。

    3. Cherry Studio V2.0 发布：从聊天客户端进化到全能 AI 工作站
      产品形态从「AI 聊天客户端」直接升级为 Agent 自主执行的一站式工作站，底层数据底座全面重构。

    4. Cloudflare 开源内部企业 AI 平台 Cloudflare OS
      Cloudflare 将内部使用的 AI 知识库 + 聊天机器人平台开源，Kenton Varda 在 Twitter 上透露更多架构细节。

    5. Rust 语言宣布 LLM 政策
      Rust 官方明确：LLM 输出不得出现在公开文档/PR描述/GitHub评论中（除非明确标注），LLM 只能辅助分析不能替代创造。

    架构 & 基础设施¶

    1. Deno 团队开源 Celld：可自托管的分布式 Durable Objects
      Ryan Dahl 团队出品，每个对象是独立的 SQLite 数据库，让你能在自己机器上运行类 Cloudflare Workers/Durable Objects。

    2. 2027 年全年 DRAM/HBM 内存产能已全部售罄
      受 AI 需求驱动，三星、SK 海力士、美光三大巨头 2027 年产能已被长期协议预订一空，NAND 也将在 8 月底前售罄。

    3. 微软要求工程师不要最大化 AI Token 使用
      微软执行副总裁 Jay Parikh 发全员邮件：将 GPT-5.6 设为内部默认模型，各部门设 Token 预算目标，聚焦业务成果而非 Token 消耗量。
