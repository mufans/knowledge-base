## 趋势观察

- **AI Agent 安全成焦点**：GitLost 和 Fedora 失控案例表明，agent 的安全边界和权限控制是今年最关键的基础设施问题
- **Agent 基础设施层爆发**：从路由器（Millwright）到工具集成（Strata MCP）到部署平台（Terminal Use），Agent infra 生态快速成型
- **成本优化受关注**：Tokenless 和 LLM Router 的出现说明，随着 agent 大量使用，token 成本优化成为刚需
- **桌面 Agent 新范式**：Screenpipe 和 Yorishiro 代表了 agent 从 API 调用走向桌面交互的趋势
- **移动端 AI 测试空白待填**：Alumnium 是少有的移动端+AI 结合项目，这个方向潜力大但关注度还不够
